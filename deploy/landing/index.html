Mii-nagement

Little lives. Real work.

A cozy island where your coding agents live, carry tasks from building to building, and ship real pull requests. You keep them happy and answer when they need you.

Your project is an island

The town layout is the workflow. Residents walk your task down the roads, one building at a time.

🏝️

Found an island

Every island is a git repository: a new one, a GitHub clone, or a folder you already have.

💬

Answer bubbles

When a resident needs a decision or permission to run a command, a bubble pops up over their head.

📮

Ship pull requests

Finished work leaves the island at the Post Office as a pull request on GitHub.

Meet the residents

Each resident has a job, a personality and a brain. Sliders set how blunt, careful, chatty or creative they are, and their mood changes as they work: happy, focused, confused, tired or proud.

PlannerCoderReviewer

Read the island news

Every island prints its own gazette: who shipped what, who fell asleep at the Courthouse, and how many pull requests went out this week.

Insights shows packages done per day, the test pass rate and how fast you answer bubbles.

Grow an archipelago

One island per project, all in the same sea. The "Waiting on you" list gathers every bubble from every island in one place.

Around town

The classic town plan. Build your own in build mode, and choose which roads a package takes when a step passes or fails.

1MailboxTasks arrive and get planned.
2WorkshopThe code gets written.
3LabThe tests run.
4CourthouseA reviewer reads the change.
5Post OfficeOut it goes as a pull request.

Get the desktop version

The island runs best on your own computer.

  • Smooth 3D with the full renderer and textures
  • Real agents, using the Claude Code, Codex or Gemini CLI logins you already have
  • Islands are git repositories on your machine; agents work in their own worktrees
  • Mock mode to try it first, at no cost
Install uv and Godot 4
brew install uv
Then Godot 4.4 or newer from godotengine.org. Linux and Windows: see the README.
Get the code
git clone https://github.com/jkusuda/Mii-nagement.git cd Mii-nagement
Start the island
make dev
make dev uses pretend agents; make uses real ones.

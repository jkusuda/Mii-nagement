Little lives. Real work.

Become the caretaker of an island full of tiny coders, naps, drama, and real pull requests!

Your project is an island. Your coding agents are the residents. Give them a task, watch them carry it from the Mailbox to the Post Office, and answer when a bubble pops up over somebody's head.

Get the desktop version

The island runs on your own computer, next to your repositories.

  • Smooth 3D with the full renderer and textures
  • Real agents, using the Claude Code, Codex or Gemini CLI logins you already have
  • Islands are git repositories on your machine; agents work in their own worktrees
  • Mock mode to try it first, at no cost (Settings > Mock agents)
Download and install Download for Mac (.dmg) Open the .dmg and drag Mii-nagement onto Applications. Apple Silicon and Intel.
Open it the first time Double-click Mii-nagement in Applications. macOS says it can't verify the app: click Done. Then open System Settings > Privacy & Security, scroll down to "Mii-nagement was blocked", click Open Anyway, and confirm with your password. You only do this once. The app isn't notarized by Apple (that needs a paid developer account), so macOS asks once. The first launch also sets up its backend, which takes about a minute and needs the internet.
Windows, Linux, or from source
Install uv and Godot 4
brew install uv
Then Godot 4.4 or newer from godotengine.org. Linux and Windows: see the README.
Get the code
git clone https://github.com/jkusuda/Mii-nagement.git cd Mii-nagement
Start the island
make dev
make dev uses pretend agents; make uses real ones.
